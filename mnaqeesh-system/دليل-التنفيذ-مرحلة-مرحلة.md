# المرحلة 2 — نسخ المفاتيح

**لماذا؟** الموقع يحتاج مفتاحين ليتصل بقاعدة البيانات.

### الخطوات

1. Supabase ← `Settings` (الترس أسفل القائمة) ← `API Keys`
2. **المفتاح العام:** تحت عنوان **Publishable key** ← اضغط أيقونة النسخ 📋 بجانب `default`
   - يبدأ بـ `sb_publishable_`
3. **المفتاح السري:** انزل لأسفل الصفحة إلى **Secret keys**
   - إن لم يوجد مفتاح، اضغط **`+ New secret key`** ← اكتب `default` ← **Create**
   - اضغط 📋 لنسخه — يبدأ بـ `sb_secret_`

### ⚠️ تنبيهات
- **لا تخلط بينهما.** العام يبدأ بـ `sb_publishable_` والسري بـ `sb_secret_`.
- **المفتاح السري لا يُشارَك مع أحد** ولا يوضع في GitHub ولا في الإضافة. مكانه الوحيد: ملف `.env` ولوحة Vercel.

### 📤 ماذا ترسل لي
> المفتاح **العام** فقط. (السري احتفظ به — سنستخدمه في ملف `.env` عندك، ولا حاجة لإرساله.)

# المرحلة 5 — تفعيل الدخول بجوجل

**لماذا؟** لتسجيل دخول المستخدمين بحساباتهم.

> ⚠️ **مهم جدًا:** جوجل يطلب **خانتين مختلفتين**، وكثير من الناس يضع العنوان في الخانة الخطأ.
> اقرأ بعناية: العنوان الذي يبدأ بـ `supabase.co` يذهب في خانة **Authorized redirect URIs**، ورابط موقعك يذهب في **Authorized JavaScript origins**.

### الخطوة 5-أ: من Supabase احصل على عنوان التحويل

1. Supabase ← `Authentication` ← `Providers`
2. اضغط **`Google`** ← فعّله (المفتاح `Enable Sign in with Google`)
3. على نفس الصفحة سترى **`Callback URL (for OAuth)`** — انسخه 📋
   - شكله المتوقع:
     ```
     https://czgxygcjyvfkhsuoearu.supabase.co/auth/v1/callback
     ```
   > ⚠️ استخدم **العنوان المعروض عندك في الصفحة**، لا تعتمد على نسخي اليدوي إن اختلف.

### الخطوة 5-ب: أنشئ تطبيق OAuth في جوجل

1. افتح [console.cloud.google.com/auth/clients/create](https://console.cloud.google.com/auth/clients/create)
2. إن طلب منك إنشاء مشروع: اكتب `mnaqeesh` ← **Create**
3. إن طلب **OAuth consent screen** / **Branding**: املأ اسم التطبيق (`مناقيش`) وبريدك ← **Save**
4. نوع التطبيق: **`Web application`**
5. الاسم: `mnaqeesh web`
6. **خانة `Authorized JavaScript origins`** ← اضغط `+ Add URI` وضع **رابط Vercel فقط** (بدون أي مسار):
   ```
   https://mnaqeesh-xxxx.vercel.app
   ```
7. **خانة `Authorized redirect URIs`** ← اضغط `+ Add URI` وضع **عنوان Supabase الذي نسخته في 5-أ**:
   ```
   https://czgxygcjyvfkhsuoearu.supabase.co/auth/v1/callback
   ```
8. اضغط **`Create`**
9. ستظهر نافذة فيها **`Client ID`** و **`Client Secret`** — انسخهما 📋

### الخطوة 5-ج: ضعهما في Supabase

ارجع إلى صفحة Google في Supabase والصق:
- `Client ID`
- `Client Secret`

ثم **`Save`**.

### الخطوة 5-د: أضف رابط موقعك في Supabase

Supabase ← `Authentication` ← `URL Configuration`:
- **`Site URL`** ← ضع رابط Vercel:
  ```
  https://mnaqeesh-xxxx.vercel.app
  ```
- **`Redirect URLs`** ← اضغط `Add URL` **مرتين** وأضف:
  ```
  https://mnaqeesh-xxxx.vercel.app/auth/callback
  https://mnaqeesh-xxxx.vercel.app/connect
  ```
- اضغط **`Save`**

### ✅ كيف تتأكد
- في Supabase: صفحة `Providers` تعرض Google **مفعّلًا**.
- في Supabase: `URL Configuration` تعرض الرابطين.

### ❌ أخطاء شائعة
| الخطأ | السبب |
|---|---|
| `redirect_uri_mismatch` | وضعت عنوان Supabase في خانة JavaScript origins، أو العكس |
| `Access blocked` | OAuth consent screen لم يُكمل، أو بريدك غير مضاف في **Audience/Test users** |
| يعود لنفس الصفحة | **Redirect URLs** في Supabase ناقص (الخطوة 5-د) |

### 📤 ماذا ترسل لي
> «المرحلة 5 نجحت» — أو صورة الخطأ إن ظهر.

   ✅ **هذا مقصود ومطلوب** — كل حساب جديد يبدأ معطّلًا. **ليست مشكلة.**
3. Supabase ← `SQL Editor` ← `+ New query` ← الصق هذا (غيّر البريد لبريدك الحقيقي):
   ```sql
   select public.promote_admin('your-email@gmail.com');
   ```
4. اضغط **`Run`** ← ستظهر رسالة:
   ```
   تم ترقية your-email@gmail.com إلى مدير نظام مفعّل.
   ```
5. ارجع للموقع واضغط `F5` (تحديث) ← ستدخل لوحة مناقيش كـ **مدير النظام**

### ✅ كيف تتأكد
ترى لوحة فيها إحصائيات وتبويبات: **المنشورات** · **الأعضاء والصلاحيات** · **سجل النشاط**

← معناه أنك لم تُكمل الخطوة 1، أو أن البريد مكتوب خطأً. راجع البريد في صفحة `Authentication` ← `Users`.

# المرحلة 8 — تثبيت الإضافة واختبارها

### الخطوات

1. افتح **Chrome** واكتب في شريط العنوان:
   ```
   chrome://extensions
   ```
2. فعّل **`وضع المطوّر / Developer mode`** (المفتاح أعلى اليمين)
3. اضغط **`تحميل غير مضغوط / Load unpacked`**
4. اختر هذا المجلد بالضبط:
   ```
   C:\Users\saadm\Desktop\Facebook Post Saver (v1.0.0)\facebook-post-saver
   ```
   ⚠️ **ليس** مجلد `mnaqeesh-system`
5. افتح [facebook.com](https://facebook.com) ← اضغط أيقونة الإضافة في شريط المتصفح
6. سترى شريطًا بعنوان **«مناقيش»** وزر **«تسجيل الدخول بجوجل»** ← اضغطه
7. ستُفتح صفحة `/connect` ← ستظهر رسالة **نجاح الربط**
8. ارجع لفيسبوك ← تصفّح ← احفظ أي منشور (زر الحفظ في الإضافة)

### ✅ كيف تتأكد

```

```

1. تأكد أن حسابك **نشط** في لوحة الأعضاء

3. جرّب زر **«إرسال منشوراتي القديمة»**
