### الخطوة 1 — تنفيذ ملف قاعدة البيانات (🔴 الأهم)

المشروع جديد، فلا يوجد فيه أي جدول بعد. بدون هذه الخطوة **لن يعمل أي شيء**.

1. افتح [supabase.com](https://supabase.com) ← مشروع **`mnaqeesh-Harness`**
2. القائمة اليسرى ← **SQL Editor** ← **+ New query**
3. افتح هذا الملف بالمفكرة وانسخ **كل** محتواه (`Ctrl+A` ثم `Ctrl+C`):
   ```
   supabase\migrations\0001_mnaqeesh.sql
   ```
4. الصقه في Supabase واضغط **Run**
5. يجب أن ترى: **`Success. No rows returned`**

**للتحقق:** القائمة اليسرى ← **Table Editor** ← يجب أن ترى 5 جداول:
```
posts · profiles · languages · translations · activity_log
```

> إن ظهر خطأ أحمر، انسخ نصه كاملًا ولا تكمل.

### الخطوة 2 — ملء المفتاحين الناقصين

الملفان `.env` و `.env.local` فيهما الرابط فقط، وينقصهما مفتاحان.

**أ) احصل على المفتاحين** من Supabase ← `Settings` ← `API Keys`:
- **Publishable key** ← اضغط 📋 (يبدأ بـ `sb_publishable_`)
- **Secret keys** ← انزل لأسفل الصفحة ← إن لم يوجد اضغط `+ New secret key`
  ← انسخه 📋 (يبدأ بـ `sb_secret_`)

🔒 **المفتاح السري لا ترسله لأي أحد ولا تضعه في GitHub.**

**ب) الصقهما في الملفين** — افتح كل ملف بالمفكرة، وعدّل السطرين الأخيرين:

```env
NEXT_PUBLIC_SUPABASE_URL=https://czgxygcjyvfkhsuoearu.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
SUPABASE_SERVICE_ROLE_KEY=sb_secret_...
```

⚠️ القيمة بعد `=` مباشرة — **بدون مسافات وبدون علامات تنصيص `"`**.

**ج) الملفان الواجب تعديلهما:**
```
mnaqeesh-system\.env
mnaqeesh-system\.env.local
```

### الخطوة 3 — تفعيل الدخول بجوجل

1. أنشئ بيانات OAuth من [console.cloud.google.com](https://console.cloud.google.com):
   - **APIs & Services** ← **OAuth consent screen** ← **External** ← املأ الاسم وبريدك ← **Save**
   - **Credentials** ← **Create Credentials** ← **OAuth client ID** ← النوع **Web application**
   - في **Authorized redirect URIs** أضف بالضبط:
     ```
     https://czgxygcjyvfkhsuoearu.supabase.co/auth/v1/callback
     ```
   - **Create** ← انسخ **Client ID** و **Client Secret**

2. في Supabase ← **Authentication** ← **Providers** ← **Google** ← فعّله والصق القيمتين ← **Save**
