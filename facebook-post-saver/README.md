# Facebook Post Saver v2.13.0

## الجديد في v2.13.0 — الربط بنظام «مناقيش»
- زر «تسجيل الدخول بجوجل» في نافذة الإضافة يفتح صفحة الربط في موقع مناقيش.
- كل منشور يُحفظ محليًا كما كان، وتُرسل نسخة منه إلى مناقيش تلقائيًا. الحذف من الإضافة يحذف نسختك هناك.
- عند انقطاع الإنترنت تنتظر المنشورات وتُرسل لاحقًا تلقائيًا.
- زر «إرسال منشوراتي القديمة» يرفع كل ما حُفظ قبل الربط.
- يجب أن يضيف المدير بريد Gmail الخاص بك في صفحة «الفريق» داخل مناقيش.


إضافة محلية لحفظ منشورات Facebook في IndexedDB، مع تصدير Excel وJSON وMarkdown وWordPress WXR، وتقسيم ملفات التصدير حسب السنة أو الشهر.


## الجديد في v2.12.0
- تحسين استخراج تاريخ ووقت المنشور: تُفضّل بيانات timestamp المطلقة المرتبطة بالمنشور، مع محاولة إظهار tooltip التوقيت من رابط المنشور عند الحاجة.
- إلغاء fallback النسبي عند الحفظ حتى لا تُؤخذ دقائق وقت الضغط الحالية وتُركّب على ساعة منشورة قديمة؛ عند عدم توفر timestamp مطلق يبقى التاريخ/الوقت فارغًا بدل حفظ وقت غير دقيق.
- اختيار أعلى مصدر متاح للصور من `srcset` قبل `currentSrc` عند حفظ رابط التحميل المباشر.
- حفظ رابط الفيديو المباشر المتاح من عنصر `<video>` في حقل `videoDirectUrl` مع الإبقاء على رابط صفحة الفيديو في `videoUrl`.
- إضافة زر تنزيل صغير بجوار كل رابط صورة/فيديو لتنزيل أعلى جودة مباشرة محفوظة متاحة باستخدام Chrome Downloads API.
- إضافة فلاتر لكل الأعمدة: الرقم، الحساب، التاريخ، الوقت، الجمهور، النص، وجود روابط الصور، وجود رابط الفيديو، ووجود رابط المنشور.
- إزالة عمود «حالة التصدير» من الجدول ومن ملف Excel.

## الجديد في v2.12.3
- إضافة تصدير **WordPress WXR XML** متوافق مع مستورد WordPress.
- كل منشور محفوظ ينتج عنصر `<item>` مستقلًا من نوع `post`، وبالتالي عدد منشورات WordPress يساوي عدد الصفوف المصدّرة.
- النص المستخدم في WordPress يأتي من Markdown المعدّل إن وُجد، وإلا من النص الأصلي.
- يتم إنشاء عنوان المنشور تلقائيًا من أول عنوان Markdown، أو من أول فقرة، مع fallback واضح.
- حفظ بيانات Facebook الأساسية في `postmeta` مثل رابط المنشور، الحساب، التاريخ، الوقت، الجمهور، روابط الصور والفيديو.
- الصور المباشرة المتاحة تُضمّن في محتوى المقال كصور خارجية، ويمكن أيضًا تضمين عناصر مرفقات في تطوير لاحق؛ ملفات الوسائط نفسها لا تدخل داخل WXR لأن WXR لا يحتوي الملفات الثنائية.
- منشورات WordPress المصدّرة تُنشأ كـ `draft` افتراضيًا حتى تتم مراجعتها قبل النشر.
- احترام تقسيم التصدير الحالي: الكل / ملف لكل سنة / ملف لكل شهر.
- تعليم الصفوف كمُصدّرة بعد نجاح تنزيل ملف WXR.
- الحفاظ على أولوية إشارة الزمن المرتبطة بالمنشور نفسه وتقليل الاعتماد على `header` الواسع الذي قد يلتقط أوقات التعليقات.
- تصميم بصري جديد بألوان الهوية: أخضر #256f4c، بني #8c7048، ذهبي #B59059، فاتح #E5E5CB، وخلفية #fafbf7.
- زر حذف مباشر لكل صف داخل عمود الرقم.
- تقليل ارتفاع الصفوف ومسافات الجدول لعرض عدد أكبر من المنشورات.
- تحسين استيراد JSON ليدعم BOM وصيغ التصدير السابقة والجذور `rows/posts` مع رسالة خطأ تفصيلية.

## الاستيراد في WordPress
1. افتح WordPress ثم **أدوات → استيراد → WordPress**.
2. ثبّت/شغّل WordPress Importer.
3. اختر ملف `.xml` الناتج من الإضافة.
4. في خطوة تعيين المؤلف، اربط `facebook-post-saver` بالمستخدم الذي تريد أن يملك المنشورات.
5. استورد الملف.

يُستحسن إبقاء خيار **Download and import file attachments** مفعّلًا إذا كانت روابط الصور الخارجية ما زالت متاحة وقت الاستيراد. مستندات WordPress الرسمية توضح أن WXR ينقل بيانات المنشورات والمرفقات كتعريفات/روابط، وليس الملفات الثنائية نفسها.

## ملاحظة الوسائط
رابط الصورة أو الفيديو المباشر المحفوظ من Facebook CDN قد يكون مؤقتًا أو منتهي الصلاحية لاحقًا. زر التنزيل يستخدم الرابط المباشر الأعلى جودة المتاح وقت الحفظ، ويرفض الروابط الخارجية غير المسموح بها حفاظًا على أمان الإضافة. لا يمكن ضمان نجاح التنزيل إذا انتهت صلاحية رابط Facebook الموقّع.

بالنسبة لبعض فيديوهات Facebook التي تُشغّل عبر `blob:`/Media Source ولا تعرض رابط ملف مباشر في الصفحة، قد يظهر زر التنزيل بحالة غير متاحة بدل تنزيل ملف غير صالح.


## ملاحظة التاريخ والوقت
حقول التاريخ والوقت تأتي من timestamp المرتبط بالمنشور نفسه قدر الإمكان. عند توفر بيانات مطلقة (`data-*`/`datetime`/tooltip) تتم الأولوية لها. عند غياب مصدر مطلق لا يتم اشتقاق وقت «دقيق» من عبارة نسبية مثل «منذ X ساعات»، حتى لا تختلط دقائق وقت الحفظ مع وقت النشر.
